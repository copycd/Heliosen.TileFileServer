[윈도우용]
publish.ps1


[리눅스용]
리눅스 OS에서
publish-linux.sh


아니면, 윈도우 PowerShell에서 
.\publish.ps1 -Rid linux-x64
윈도우에서 빌드한건 리눅스에서 실행할때 권한문제가 있음.

리눅스 서버로 옮긴 뒤:

  # 실행 권한이 필요하다. 윈도우(NTFS)에는 실행 비트가 없어서
  # zip/scp 로 옮기면 권한이 떨어져 나가고 'Permission denied' 가 난다.
  chmod +x Heliosen.TileFileServer
  TileServer__Root=/srv/tiles ./Heliosen.TileFileServer

  # chmod 를 못 하는 상황이면 dll 을 직접 실행해도 된다(실행 비트가 필요 없다).
  TileServer__Root=/srv/tiles dotnet ./Heliosen.TileFileServer.dll

systemd 로 등록:
  sudo cp deploy/heliosen-tileserver.service /etc/systemd/system/
  sudo systemctl daemon-reload && sudo systemctl enable --now heliosen-tileserver
